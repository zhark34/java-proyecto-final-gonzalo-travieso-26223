# API de artículos

Proyecto de una API REST para administrar artículos. Está desarrollado con Spring Boot y guarda los datos en MySQL.

## Funciones

- Listar y buscar artículos.
- Crear, editar y eliminar artículos.
- Guardar el nombre y el precio de cada artículo.

## Tecnologías

- Java y Spring Boot
- Spring Data JPA
- MySQL
